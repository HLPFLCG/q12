## 🎯 Deployment Instructions

### Step 1: Choose Your Platform

**Vercel (Recommended)** - https://vercel.com/

**Netlify** - https://netlify.com/

**Cloudflare Pages** - https://pages.cloudflare.com/
- Fastest CDN
- Free tier available
- GitHub integration

---

### Step 2: Deploy (Vercel Example)

1. **Go to** https://vercel.com/signup
2. **Sign up** (free)
3. **Click** "Add New" → "Project"
4. **Import** GitHub repo: `HLPFLCG/q12`
5. **Select branch**: `production-ready` ⭐
6. **Configure** (if needed):
   - Framework Preset: Next.js
   - Root Directory: `./`
7. **Click** "Deploy"

---

### Step 3: Add Environment Variable

After initial deployment:

1. Go to Project Settings → Environment Variables
2. Add:
   - **Name**: `NEXT_PUBLIC_FORMSPREE_ID`
   - **Value**: Your Formspree ID (from https://formspree.io/)
3. Click "Save"
4. Redeploy

---

### Step 4: Add Your Custom Domain

1. In Vercel dashboard, go to Settings → Domains
2. Click "Add Domain"
3. Enter your domain
4. Update DNS records (Vercel will provide instructions)
5. Wait for propagation (5-30 minutes)
